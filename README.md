The joke: a forecast for a city that doesn't exist, so the weather itself is impossible — yesterday is falling, regrets are scattered, and the high is your own forgotten errand.

> Today in Nowhereville: 100% chance of yesterday, scattered regrets by lunchtime, and a high of whatever you forgot.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (115 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
